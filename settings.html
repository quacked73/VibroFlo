Backup & Transfer
Presets, session history, Luminous settings, and light-signal format tags all live only on this device right now. Export them as one file to move to another device, or attach it to an email as a backup. This does not include the actual audio files you've uploaded locally — those are large enough to make a file like this impractical to email, and would need re-adding on the new device. Files hosted through Cloudinary don't have this problem at all, since they're already reachable from anywhere.
